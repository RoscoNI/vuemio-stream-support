# Vuemio Stream for Apple TV — Support & Documentation

This repository hosts the official GitHub Pages support website, FAQ, privacy policy, and TMDB attribution for **Vuemio Stream**, a native IPTV media player and television guide for tvOS.

Live site: [https://rosconi.github.io/vuemio-stream-support/](https://rosconi.github.io/vuemio-stream-support/)

## Features Covered
- Application overview (100% free tvOS IPTV player)
- TMDB API attribution and compliance notices
- Support & FAQ with contact information
- Privacy policy detailing on-device local storage and zero telemetry
